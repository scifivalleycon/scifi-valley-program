Sci-Fi Valley Con Attendee App V4.42 — Program Tools SAFE PATCH

NEW PULL-DOWN PROGRAM TOOLS
A small PROGRAM TOOLS handle is available at the top of the app.
Users can tap it or pull it downward to open the drawer.

TEXT / READABILITY
- A- and A+ controls
- 90%, 100%, 115%, and 130% text sizes
- Reset button
- Preserves the app's relative typography instead of making every label the same size
- Remembers the selected size in localStorage on that device
- Dynamically generated schedule, guest, vendor, FAQ, alert, and modal text also inherits the selected readability setting

PDF / SHARE
- Creates a REAL text-based PDF directly in the browser without an external library
- Includes Event Details and hours
- Latest Event Updates
- My Con selections
- Show Schedule including Guest Panels, Trivia, photo ops, and autograph availability
- Celebrity Guests
- Celebrity pricing when published
- Event Guide
- Vendor Directory and floor locations, including vendor descriptions
- FAQ
- Uses the native mobile share sheet when PDF file sharing is supported, allowing the attendee to use Messages, Mail, Files, Drive, AirDrop, etc.
- On browsers that cannot share a PDF file directly, downloads the PDF instead

PRINT / SAVE PDF
- Builds an easy-to-read print-only version of the program
- Opens the browser/device print dialog
- The print dialog can be used for a physical printer or Save as PDF

REFRESH APP & PAGE
- Force-refreshes the latest backend program JSON
- Checks for an updated Service Worker
- Reloads the page afterward
- Existing My Con selections, registration, notification settings, and text-size preference remain stored locally
