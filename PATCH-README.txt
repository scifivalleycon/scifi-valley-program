Sci-Fi Valley Con Attendee App V4.56 — Large Header Word Fit

Rolled forward from Program V4.55 Full-App Text Scaling.

Changes:
- Simplifies the Text Size description in Program Tools.
- Keeps the full-app text scaling behavior from V4.55.
- Page header titles no longer split or break through the middle of long words.
- Long title words such as INTERACTIVE and CELEBRITY are automatically fitted to the largest enlarged size that still fits the available header line.
- Multi-word page titles continue onto the next line only at normal spaces between words.
- Header title accent words inherit the fitted title size so mixed-color titles stay visually consistent.
- Header fitting recalculates when the browser/window width changes.
- Text-size choice continues to be saved on the device.

No V4.55 functionality was removed.
