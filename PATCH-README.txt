Sci-Fi Valley Con Attendee App V4.51 — Extra-Large Accessibility Text

TEXT SIZE OPTIONS
- 90%
- 100%
- 115%
- 130%
- 150%
- 175%
- 200%

ACCESSIBILITY BEHAVIOR
- Small readable content can use the full 200% range.
- Medium headings grow more conservatively.
- Large decorative/display typography remains protected.
- At 150% and above, dense grids collapse to a single readable column where possible.
- Buttons and controls receive larger tap targets.
- Text that was previously forced onto one line is allowed to wrap.
- At 175% and 200%, additional horizontal compression is removed.
- Tables become horizontally scrollable rather than overlapping.
- Existing selected font size remains stored on the device.
